What this SEO audit checks

The tool checks accessible HTML for a page title, meta description, canonical URL, heading structure, language attribute and visible link count. These are useful on-page signals, but search visibility also depends on content quality, relevance, technical accessibility and many other factors.

If the audit cannot fetch a page

Modern browsers restrict cross-origin requests unless the target site permits them. A failed browser fetch does not necessarily mean the website has an SEO problem.
